# Print Production Oman — GitHub Pages website

This package contains the final approved single-page design. No installation or build command is needed. All CSS and JavaScript are embedded in index.html.

## Upload
1. Extract the ZIP on your computer.
2. Open your GitHub repository: https://github.com/PrintProduction/print-production-oman
3. Use Add file → Upload files. Drag index.html, the images folder, README.md and .nojekyll from the extracted folder into GitHub. Upload the contents, not the ZIP or its outer folder. Keep index.html at the repository root, next to images.
4. Commit the upload to your main branch. Matching filenames replace the previous versions.
5. Open Settings → Pages. Select Deploy from a branch, main, and / (root), then Save. If Pages already uses main / (root), leave it configured that way.
6. Wait for deployment to finish and open the link shown in Pages. Refresh the browser if it shows an older version.

## Image folders

images/thumbs/ contains the matching uniform gallery thumbnails.
Keep both folders and filenames intact. To change a design, replace both its full image and thumbnail, or edit its image paths and descriptions in index.html.
